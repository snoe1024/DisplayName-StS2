[b]Клиентский мод: больше не влияет на игровой процесс![/b]

[b]Ваше отображаемое имя используется везде в совместной игре.[/b]
Выбранное отображаемое имя используется как имя игрока вместо вашего имени Steam.
Оставьте поле пустым, чтобы сохранить имя Steam.

[b]Если у других игроков нет этого мода[/b]
Если у хоста есть RitsuLib, игроки с этим модом обмениваются отображаемыми именами.
Игроки без этого мода видят ваше имя Steam.
Без RitsuLib у хоста меняется только ваше собственное отображаемое имя на вашем экране.

[b]Поддержка веток[/b]
Поддерживает стандартную ветку и Public Beta.

[b]Необходимый мод[/b]
RitsuLib (устанавливается автоматически как зависимость Мастерской)
[b]Чтобы мод больше не требовался всем участникам, зависимость от BaseLib была заменена.[/b]
Если мод не загружается правильно после обновления, проверьте, установлен ли RitsuLib.
